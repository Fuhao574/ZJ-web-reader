# 线上进度同步

前端仍可公开阅读，只有同步需要密钥。本地书籍不上传；密钥遗失不能找回。

1. 在新建的 MySQL 数据库中导入 `schema.sql`。需要 PHP 8.0+ 与 `pdo_mysql`。
2. 运行 `npm run build`，上传 `dist/` 内文件到阅读器网站目录，其中 `api/` 是 PHP 接口。不要将它放在只支持静态文件的托管平台。
3. 在**网站目录外的同级目录**建立 `reader-private/config.php`，填入数据库配置。参考 `config.example.php`；真实本机配置已单独保存，不进入 Git 或构建产物。

```text
阅读器域名目录/
├── reader-private/
│   └── config.php       ← 不可通过网址访问，权限 600 或主机支持的最小权限
└── public_html/         ← 网站根目录，名称以实际主机为准
    ├── index.html
    ├── api/
    │   ├── index.php
    │   ├── contract.php
    │   └── .htaccess
    ├── assets/
    ├── books/
    └── catalog.json
```

若主机的子域名根目录不同，保证 `reader-private` 与该根目录同级；接口会先查网站目录的上一级，再兼容本地项目目录结构。也可由 PHP 环境变量 `READER_CONFIG_FILE` 指定绝对配置路径。`origin` 必须是实际 HTTPS 站点来源，不带尾斜杠。

本机 `localhost` 指的是开发电脑，不是你的主机；不能用它在本机验证线上数据库。线上第一次验证需要通过阅读器创建同步密钥（会写入数据库），或在主机上用随机测试密钥做一次受控联调。

## 使用

点右上角「同步」创建密钥，自行保存，在另一设备输入同一密钥连接。连接后打开同一本书即可读取进度。冲突时明确选择本机或线上位置。断开只退出本机，删除线上进度会使整份密钥失效。

删除会清除对应进度，服务端只保留作废密钥的哈希标记，防止其他设备用同一密钥重新创建身份。

进度按**格式与文件 SHA-256**匹配，不发送书名、正文或文件；同一内容的本地书和云端书可匹配，修改书籍内容会成为新版本。滚动保存会合并请求，网络失败保留本机与待同步位置，重新打开该书或重试时继续处理；关闭页面的最后一次请求不是绝对可靠的，因此始终保留本机记录。

接口按服务端版本号检查并发写入，不依赖设备时钟。数据限制：每个密钥最多 1000 本，每份进度请求 8KiB。建密钥每个来源 IP 每小时 10 次、接口每 10 分钟 600 次；只使用服务端看到的 IP，不信任转发头。

不要记录请求体或 Authorization 头。接口错误不输出数据库细节；配置不要放到 `public/`、`dist/` 或网页可访问目录。若 API 返回 500，检查主机是否允许 `.htaccess` 中的 `Options -Indexes`；如不允许，在面板关闭目录索引后去掉这一行。

## 本地检查

```bash
npm test
npm run test:php
```

自动测试使用内存模拟同步接口与 PHP 纯契约测试，不连接线上数据库。上线后仍需用两台设备完成 PHP/MySQL 联调，未联调不能视为已验证线上同步。

`scripts/test-sync-api.mjs` 仅接受 `127.0.0.1` 测试接口，会创建随机身份、读写并删除其记录；只对隔离的临时数据库运行。

# 纸间

TXT / EPUB 阅读器。纸面排版，进度自动保存在当前浏览器。字体优先使用系统字体，避免移动端首屏下载大量中文字体分片。

```bash
npm install
npm run dev
```

需要 Node 22.12+。开发地址：`http://localhost:5180/`。

## 云端书架

把书籍放进 `public/books/`，支持子目录。开发启动和构建时自动扫描，生成 `catalog.json`，不需要手动编辑。

TXT 默认用文件名作书名，自动识别 UTF-8 / GB18030；EPUB 优先读取书名和作者元信息。文件内容变化后自动更新版本，旧版进度不再套用。

```bash
npm run build
npm run preview
```

发布 `dist/` 内的静态文件即可。云端加书需要重新构建；只往线上目录放文件不会更新书架。仅公开有权分发的书籍，所有书籍文件（包括示例书）均不进入 Git。

构建产物不会包含原始云端 TXT / EPUB，只包含 `books/.chunks/` 的按 20 章分组数据；原始文件仅是本地构建输入。

## 本地书架

切到「本地书架」，选择设备上的 TXT / EPUB。文件只在浏览器中解析并存入 IndexedDB，不上传服务器，也不混入云端书架。支持继续阅读和移除书籍。

本地书籍不跨设备同步；清理站点数据会一并清除。浏览器不允许存储时会提示失败。单本上限 32MiB，不支持 DRM 加密书籍；EPUB 使用统一纸面排版，不执行书内脚本或样式。

## 进度同步（可选）

PHP＋MySQL 保存阅读位置，通过同步密钥连接多台设备，不要求账号登录。不上传书籍，冲突时选择保留本机或线上位置。没有配置后端时仍可正常本地阅读。后端配置见 [server/SETUP.md](server/SETUP.md)。
